Your screenshots, on your own WordPress site.

PressShot is a free Mac menu bar app. Take a screenshot or record your screen, and it uploads to your WordPress media library and puts the link on your clipboard.

Install

Paste this into Terminal and press Return:

curl -fsSL https://get-pressshot.space.fast/install.sh | sh

It downloads the latest build, checks it, puts PressShot in your Applications folder, and opens it. Run it again to upgrade. Needs macOS 12.3 or newer.

PressShot isn't notarized by Apple yet, so the Terminal install is the smooth path; a browser download would be blocked by macOS.

Then three things only you can do

  1. Allow Screen Recording when macOS asks, then quit and reopen PressShot.
  2. Connect your site. In PressShot Settings, open Upload destinations, click Connect a site, enter your site’s address, approve PressShot on the WordPress page, and save.
  3. Allow Keychain access. On the first upload after each update, enter your Mac password and choose Always Allow.

Installing with an AI agent

The installer never asks a question, so an agent can run it for you. Point it at the install guide, or have it run:

curl -fsSL https://get-pressshot.space.fast/install.sh | sh -s -- --json

It prints one JSON line with the result and the steps to hand back to you. llms.txt has the short version for agents.
